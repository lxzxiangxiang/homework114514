> C++17 | Qt 6.11 MinGW 64-bit | CMake | QGraphicsView 框架

> 一个完整的 Agar.io 风格多人球球对战游戏复刻版

### 1.2 核心概念：质量与半径

本游戏中所有球体的核心属性是**质量（Mass）**，定义为球体的面积：

```
质量 = π × 半径²
半径 = √(质量 / π)
```

半径由质量导出。吞食、分裂、吐孢等操作均以质量计，公式简洁直观。

## 4. 运行时生命周期

### 4.1 启动→菜单

```
main()
  └─ QApplication a(argc, argv)
  └─ GameView view
       ├─ m_gameScene = new GameScene()
       ├─ setScene(m_gameScene)
       ├─ m_uiManager = new UIManager(m_gameScene, view)
       ├─ setWindowTitle("球球大乱斗")
       ├─ resize(1280, 720)
       ├─ setBackgroundBrush(Qt::black)
       ├─ m_gameTimer = new QTimer(16ms) → connect(advanceGame)
       └─ returnToMenu()
            ├─ m_state = Menu → stop timer
            ├─ resetTransform() + centerOn(640,360)
            └─ showMenu()
  └─ view.show() → a.exec()
```

### 4.2 开始游戏

```
Enter → keyPressEvent(Enter)
  └─ startGame()
       ├─ AIController::resetState 清理旧AI状态
       ├─ setScene(nullptr) → delete m_gameScene → delete m_uiManager
       ├─ m_gameScene = new GameScene()
       │    ├─ setSceneRect(0,0,5000,5000)
       │    ├─ spawnFood(200)
       │    ├─ spawnAIBall() × 20  (每只3s护盾增益)
       │    └─ new Ball(质量707, 红色, isPlayer=true)
       │         └─ skill=Shield, skillTimer=3.0f
       ├─ setScene(m_gameScene)
       ├─ m_uiManager = new UIManager(...)
       ├─ resetTransform()
       ├─ m_keysPressed.clear()
       ├─ m_state = Playing
       └─ m_gameTimer→start()
```

### 4.3 主循环（每16ms）

```
QTimer::timeout → advanceGame()
  if (m_state != Playing) return;

  ① processPlayerInput()           ← WASD→方向, Space→wantSplit, E→wantEject
  ② m_gameScene→updateGame(0.016)  ← 17步游戏逻辑
  ③ 遍历playerBalls: totalMass + activeCount + 效果文本 + canSplit
  ④ 胜负判定 (totalMass≤0→gameOver, ≥阈值→victory)
  ⑤ updateCamera()                 ← 质量加权中心 + lerp + 动态zoom
  ⑥ updateHUD(分数,时间,半径,AI数,效果,分裂状态,zoom)
```

### 4.4 暂停/继续

```
暂停: ESC → pauseGame()
        Paused → stop timer → resetTransform+centerOn(640,360) → showPause()
继续: ESC → resumeGame()
        Playing → start timer → hideAll()
```

### 4.5 失败/胜利/回菜单

```
失败: playerBalls空 → gameOver() → stop + reset + showGameOver(score,time)
胜利: totalMass≥阈值 → victory()  → stop + reset + showVictory(score,time)
菜单: M → returnToMenu()          → stop + reset + showMenu()
重新: Enter → startGame()
```

## 5. updateGame(dt) 17步详解

```
GameScene::updateGame(0.016)
│
├─ 1. 移动玩家球体: for ball∈playerBalls: ball→move(inputDir, dt)
├─ 2. 分裂 (wantSplit): 拷贝列表, for ball: ball→split(inputDir) → addPlayerBall
├─ 3. 吐孢 (wantEject): for ball: ball→eject() → addEjectBall
├─ 4. allBalls = playerBalls + aiBalls
├─ 5. AI更新: 拷贝aiBalls, for ai: updateAI(ai, allBalls, foods, dt)
│       → pendingSplitBall → addItem + aiBalls.append
├─ 6. 球体计时器: for ball: ball→update(dt)  (技能/减益递减)
├─ 7. Magnet磁力: 吸引半径×4范围内Food (clamp边界)
├─ 8. EjectBall更新: 飞行+衰减+生命周期
├─ 9. SkillBall更新: 生命周期递减
├─10. Hazard更新: 生命周期递减
├─11. 技能球生成 (2~4s间隔, 上限30)
├─12. 危险物生成 (3~6s间隔, 上限20)
├─13. 同源吸引力: applyAttraction(dt) (clamp边界)
├─14. 碰撞检测: checkCollisions() — 5种碰撞逐个处理
├─15. 移除死亡实体: removeDeadEntities() + AIController::resetState
├─16. 补豆子→MAX_FOOD=500, 补AI→AIBALL_COUNT_INIT=20
└─17. survivalTime += dt
```

## 6. 各系统详解

### 6.1 移动系统

```
// Ball::move(dx, dy, dt)
speed = BASE_SPEED × √(MIN_MASS / mass)    // 300 × √(314 / mass)
if 加速增益:  speed ×= 1.5
if 陷阱减益:  speed ×= 0.5
setPos(pos + (dx×speed×dt, dy×speed×dt))
clamp 到 [0, MAP_W] × [0, MAP_H]
```

**关键**: 速度与质量平方根反比 — 球越大越慢。等效于 `300 × √(10 / radius)`。

### 6.2 分裂系统

```
// Ball::split(direction)
条件: mass ≥ SPLIT_MASS_THRESHOLD (π×18² = 1018)
newMass = mass × 0.5              ← 质量平分
setMass(newMass)                  ← 自身缩小
new Ball(newMass, 同色, 同isPlayer, 同aiLevel) → aiId相同
方向: direction → lastDx/lastDy后备 → (1,0)后备 → ±15°随机误差
位置: pos + normalized(dir) × (2×新半径 + 30)  ← 足够远避免同帧合并
返回 newBall → GameScene::addPlayerBall()
```

### 6.3 吐孢系统

```
// Ball::eject()
条件: mass ≥ EJECT_MASS_THRESHOLD (π×25² = 1964)
newMass = mass - EJECTBALL_MASS     ← mass - 201 (转移π×8²质量)
setMass(newMass)
new EjectBall(pos, 同色, dir.x, dir.y)
  EjectBall: 质量201, 初速=dir×200, 每帧v×=0.98衰减, lifetime=20s
```

### 6.4 吞食系统

```
// Ball::eat(target)
newMass = self.mass + target.mass    ← 质量直接相加
setMass(newMass)
target→onEaten(this) → m_alive=false
```

**关键**: 质量直接相加，简洁直观。半径由 `√(mass/π)` 自动导出。

### 6.5 效果系统

本游戏的效果分为**增益效果**（来自技能球）和**减益效果**（来自危险物）。一个球体可同时拥有一个增益和一个减益。

| 效果 | 类型 | 时长 | 效果描述 |
|------|:---:|------|----------|
| **加速** | 增益 | 5s | 速度×1.5，绘制颜色高亮130% |
| **护盾** | 增益 | 3s | 免疫危险物碰撞，蓝色半透明外圈(+4px) |
| **巨大** | 增益 | 4s | 吃到时质量×2，到期时质量×0.6 (净收益 ×1.2) |
| **隐身** | 增益 | 6s | 透明度0.3，AI无视此球体 |
| **磁力** | 增益 | 5s | 吸引半径×4范围内的Food，颜色高亮150% |
| **炸弹** | 减益 | 0s | 质量×0.7225（瞬时，立即清除） |
| **陷阱** | 减益 | 3s | 速度×0.5，棕色半透明外圈(+2px) |
| **中毒** | 减益 | 4s | 每秒减固定质量（下限保护），绘制绿色 |

#### Grow 效果详解

```
吃到时: growOriginalMass = currentMass; setMass(mass × 2)
到期时: setMass(growOriginalMass × 0.6)
净收益: 2 × 0.6 = 1.2 倍质量
```

设计意图：给玩家短期显著增强，到期后仍有少量留存，鼓励积极使用。

#### 计时器逻辑

```
Ball::update(dt)
  if skillTimer>0: skillTimer-=dt; 到期→skill=None (Grow恢复质量)
  if debuffTimer>0: debuffTimer-=dt; 到期→debuff=None (Poison每帧减质量)
```

#### HUD 显示

合并为一行：`效果: 加速(3.2s), 中毒(1.5s)` 或 `效果: 无`

### 6.6 AI 系统

```
AIController::updateAI(ai, allBalls, foods, dt)
│
├─ decisionTimer -= dt
│
├─ 到期决策 (Level1:0.4s, Level2:0.2s, Level3:0.1s)
│   │
│   ├─ ① 威胁检测: 找半径>self×1.1且距<self×6 → 叠加逃离向量
│   ├─ ② 猎物检测(Ball): 找半径<self×0.9 → score=半径/(距+1) → 追最高分
│   ├─ ③ 追Food: 无威胁无猎物 → 遍历foods找最近豆子 → 朝其移动
│   ├─ ④ 巡逻: 无威胁/猎物/Food → 随机[0,5000]巡逻点
│   └─ ⑤ 分裂(Level≥2): 逃生(距<3r)或猎食(距<4~5r且self>prey×1.5) → split()
│
├─ 平滑转向: atan2差值 → clamp(turnSpeed×dt) → 新角度
│
└─ ai→move(currentDir, dt)
```

| 行为优先级 | 逃脱 > 追猎(Ball) > 追Food > 巡逻 |

| 等级 | 决策间隔 | 转向速度 | 分裂 | 进攻性 |
|------|----------|----------|:----:|:------:|
| 1 | 0.4s | 2.0 rad/s | 无 | 否 |
| 2 | 0.2s | 3.0 rad/s | 逃生+猎食 | 否 |
| 3 | 0.1s | 5.0 rad/s | 激进(阈值更宽) | 是 |

### 6.7 碰撞系统

```
checkCollisions()
│
├─ 构建空间网格: for ball: m_spatialGrid.add(ball)
│
├─ ① Ball↔Food: 距²≤(rB+rF)² 且 massB>massF×1.1 → eat(food), score+=1
├─ ② Ball↔SkillBall: 距²≤(rB+rS)² → applySkill(type), sb→onEaten()
├─ ③ Ball↔Hazard: hasShield()跳过, 距²≤(rB+rH)² → applyDebuff(type)
├─ ④ Ball↔EjectBall: 距²≤(rB+rE)² 且 massB>massE×1.1 → eat(eb), score+=0.5
└─ ⑤ Ball↔Ball (空间网格3×3邻域):
     同源(sameOwner) → 大球eat(小球)
     非同源 → 质量>目标×1.1且小无护盾 → eat(小), score+=半径×0.5
```

---

### 6.8 吸引力系统

```
// applyAttraction(dt)
for 同owner球对(b1,b2):
    dist = |b2.pos - b1.pos|
    attraction = 15 + 0.0003 × dist²       ← 引力公式（随距离平方增长）
    moveStep = attraction × dt / 2
    b1 += normalized(dir) × moveStep  (clamp边界)
    b2 -= normalized(dir) × moveStep  (clamp边界)
```

---

### 6.9 摄像机系统

```
// updateCamera()
① 质量加权中心: cx = Σ(x×mass)/Σmass
② 平滑跟随: smooth = current + (target-current) × 0.1 (lerp)
③ 动态zoom: targetZoom = 1.5 × (10 / maxRadius)
   m_currentZoom += (targetZoom - m_currentZoom) × 0.08  (缓动lerp)
   zoom = clamp(m_currentZoom, 0.5, 1.5)
④ resetTransform() → scale(zoom) → centerOn(smooth)
```

### 6.10 HUD 系统

6行布局: `分数 | 时间 | 半径 | AI | 效果 | 分裂`

- 无 `ItemIgnoresTransformations`，受 view 变换影响
- 每帧 `updateHUD()`:
  - 字体 = 12/zoom（抵消缩放）
  - 行高 = 18/zoom（视口恒定间距）
  - 位置 = mapToScene(10,10)（视口左上角→场景坐标）

---

### 6.11 空间网格

```
SpatialGrid (CELL_SIZE=200)
  m_grid: QHash<(cx,cy), QList<Entity*>>

add(entity):  pos/200→cell坐标 → append
getNearby(x,y,r):  中心cell + 3×3邻域 → 距离筛选(r×2)
clear():  每帧重建
```

**复杂度**: O(N) 构建 + O(N×cellAvg) 查询, 替代 O(N²) Ball↔Ball 碰撞。

```
       ├─ 抛射物: EjectBall::update()

       ├─ 吸引力: applyAttraction()
       ├─ 碰撞: checkCollisions() → Ball::eat()
       ├─ 清理: removeDeadEntities()
       └─ 补位: spawnFood/spawnAIBall
       │
       ▼
  advanceGame() [GameView]
       ├─ 胜负判定 → gameOver()/victory()
       ├─ updateCamera() → scale+centerOn
       └─ updateHUD() → 6行HUD
```
